# Shipment Extractor

Upload a United Pharmaceuticals *Delivery Shipment Report* PDF and get an Excel file (`<shipment number>.xlsx`) with two columns: **Pharmacy** and **Delivery ID**.

- Runs fully in the browser. The PDF is never uploaded anywhere.
- IDs are read from the PDF's own text, so they are copied exactly.

Open: https://safvanmelethil.github.io/shipment_extractor/
